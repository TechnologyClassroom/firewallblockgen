# [\#17 Issue](https://github.com/TechnologyClassroom/firewallblockgen/issues/17) `open`: Add abbreviated ASN descriptive name to generated scripts
**Labels**: `enhancement`, `help wanted`, `asn-to-ipset-script.sh`


#### <img src="https://avatars.githubusercontent.com/u/14501791?u=8da94d892503ab67e2bccc0cf1fedb63e4532816&v=4" width="50">[TechnologyClassroom](https://github.com/TechnologyClassroom) opened issue at [2026-05-04 16:10](https://github.com/TechnologyClassroom/firewallblockgen/issues/17):

As of now, `asn-to-ipset-script.sh` generates filenames in this syntax:

    <ASN>-ipset-<YYYYMMDD>.sh

For example, building a list to block ZSCALER would look like this:

    22616-ipset-20260504.sh

This would be an improvement:

    22616-ipset-zscaler-20260504.sh

#### <img src="https://avatars.githubusercontent.com/u/14501791?u=8da94d892503ab67e2bccc0cf1fedb63e4532816&v=4" width="50">[TechnologyClassroom](https://github.com/TechnologyClassroom) commented at [2026-05-04 16:24](https://github.com/TechnologyClassroom/firewallblockgen/issues/17#issuecomment-4372661719):

To do this, an additional optional dependency of <https://github.com/jedisct1/iptoasn-webservice/> would need to be added to `asn-to-ipset-script.sh` borrowing code from `ip-to-asn-info.sh` (which is also in the repository).

The script has CIDR addresses instead of IPs, but it would be easy enough to do.

* If iptoasn-webservice is available...
  * Take one CIDR from the list.
  * Isolate an IP address.
  * Run the IP address through the API and save the description.
  * Reduce the description to the first handful of characters.
  * Make everything lower-case.
  * Add the string to the filename.
