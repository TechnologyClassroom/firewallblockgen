In https://github.com/TechnologyClassroom/firewallblockgen/blob/main/ua-s-a-d.sh#L124 line,

```
  awk -F'"' -v ua="$ua" 'NF>=2 && $(NF-1)==ua { split($1,a," "); print a[1] }' "$log"
```

`a[1]` can be modified if the IP is in a different field. By default, it uses the first column. Some configurations use the 2nd column so `a[2]` would be right. Some configurations use the 6th column so `a[6]` would be right. This all needs to be in a configuration file.
