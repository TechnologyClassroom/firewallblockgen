I can convert the output of the ipset scripts into the format of an NGINX deny rule with this command:

    cat ipset/*-ipset-20260628.sh | grep " -A" | awk '{ print $4 }' | sed 's/^/deny /g;s/$/;/g'

Adding the output of that command to part of the NGINX config would deny traffic to those CIDR addresses from the web server layer.

It would be nice if the user could easily modify the script to provide that output without needing to run a secondary command.
