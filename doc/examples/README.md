# firewallblockgen example files

`user-agent-list.txt.example` is an example `user-agent-list.txt` file that can
be used with the `ua-s-a-d.sh` script. This can also be used as a starting
point.

Copy the file to the same directory as `ua-s-a-d.sh` with the name
`user-agent-list.txt` to try it out.

    cp user-agent-list.txt.example ../../user-agent-list.txt
